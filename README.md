# English Buddy – Fluency First + Bloom's Taxonomy

### Experimentální projekt vytvořený pomocí AI (vibe coding)

English Buddy je malý experiment, který vznikl z otázky:

**Jak využívat AI při učení angličtiny tak, aby za nás nepřemýšlela, ale pomáhala nám mluvit samostatněji, spontánněji a plynuleji?**

Základem je konverzační prompt kombinující princip *Fluency First* s revidovanou Bloomovou taxonomií kognitivních cílů.

Postupně jsem se rozhodla převést tento nápad také do jednoduché webové aplikace se šesti jazykovými misemi.

Projekt vzniká s pomocí AI metodou *vibe coding*. Sama se při tom učím, jak aplikace fungují, jak pracovat s kódem a jak je publikovat.

**Nejde o hotový ani pedagogicky ověřený nástroj. Projekt je stále ve fázi experimentování a testování.**

## Vyzkoušejte English Buddy

🌐 **Webové demo:** [Sem doplním odkaz]

Pro vyzkoušení není potřeba instalace, API klíč ani placený ChatGPT. Bezplatná verze ChatGPT je dostačující, je však nutné počítat s jejími limity.

Postup:

1. Otevřete webové demo.
2. Vyberte si jednu ze šesti jazykových misí.
3. Zkopírujte připravené instrukce.
4. Otevřete ChatGPT a vložte je do nové konverzace.
5. Vyzkoušejte rozhovor, ideálně hlasem.

## Šest jazykových misí

- **Keep Talking** – rozvíjení souvislého projevu.
- **Quick Response** – rychlé spontánní reakce.
- **Explain It Simply** – vysvětlování vlastními slovy.
- **Say It Differently** – parafrázování a flexibilita vyjadřování.
- **Defend Your Opinion** – argumentace a obhajoba názoru.
- **Real-Life Challenge** – realistické konverzační situace.

Mise vycházejí z Bloomovy taxonomie, ale nejsou zamýšleny jako rigidní posloupnost kognitivních úkolů.

Hlavním cílem je přirozená komunikace a aktivní používání angličtiny.

## Jak English Buddy funguje

Webová aplikace je vytvořena pomocí HTML, CSS a JavaScriptu.

Nepotřebuje vlastní server ani připojení k OpenAI API.

Konverzace probíhá prostřednictvím ChatGPT na účtu samotného uživatele.

Web slouží k výběru misí, přípravě instrukcí a zaznamenávání vyzkoušených aktivit.

Údaje o vyzkoušených misích se ukládají lokálně do prohlížeče. Web neshromažďuje obsah konverzací.
